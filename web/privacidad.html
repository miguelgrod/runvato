Política de privacidad

Última actualización: 17 de marzo de 2026

En runvato.com nos comprometemos a proteger la privacidad de los usuarios y a garantizar el cumplimiento de la normativa vigente en materia de protección de datos personales, en particular el Reglamento (UE) 2016/679 (RGPD) y la Ley Orgánica 3/2018 de Protección de Datos Personales y Garantía de los Derechos Digitales.

1. Responsable del tratamiento

  • Responsable: Runvato.com
  • Titular del sitio web: Miguel García
  • Correo electrónico de contacto: contacto@runvato.com
  • Sitio web: https://runvato.com

El responsable del tratamiento es la persona que determina los fines y medios del tratamiento de los datos personales recogidos a través de este sitio web.

2. Datos personales que recopilamos

Este sitio web puede recopilar los siguientes datos personales:

  • Datos que el usuario proporcione voluntariamente al contactar con el sitio web.
  • Dirección IP.
  • Datos técnicos de navegación necesarios para el funcionamiento y seguridad del sitio web.
  • Cualquier otra información que el usuario decida proporcionar voluntariamente.

3. Finalidad del tratamiento

Los datos personales recopilados se utilizan con las siguientes finalidades:

  • Atender consultas o solicitudes realizadas por los usuarios.
  • Gestionar la comunicación con los usuarios.
  • Garantizar el correcto funcionamiento y la seguridad del sitio web.
  • Cumplir con las obligaciones legales aplicables.

4. Base legal para el tratamiento

El tratamiento de los datos personales se basa en:

  • El consentimiento del usuario al contactar voluntariamente con el sitio web.
  • El interés legítimo del responsable para mantener la seguridad y funcionamiento del sitio web.
  • El cumplimiento de obligaciones legales cuando sea aplicable.

5. Conservación de los datos

Los datos personales se conservarán únicamente durante el tiempo necesario para cumplir con la finalidad para la que fueron recogidos o mientras exista una obligación legal de conservación.

6. Destinatarios de los datos

Los datos personales no serán cedidos a terceros salvo obligación legal o cuando sea necesario para la prestación de servicios técnicos relacionados con el funcionamiento del sitio web, como proveedores de alojamiento o mantenimiento.

7. Derechos de los usuarios

Los usuarios tienen derecho a:

  • Acceder a sus datos personales.
  • Solicitar la rectificación de datos inexactos.
  • Solicitar la supresión de sus datos.
  • Solicitar la limitación del tratamiento.
  • Oponerse al tratamiento.
  • Solicitar la portabilidad de los datos cuando sea aplicable.

Para ejercer estos derechos, el usuario puede enviar una solicitud al correo electrónico contacto@runvato.com, indicando el derecho que desea ejercer.

Asimismo, el usuario tiene derecho a presentar una reclamación ante la Agencia Española de Protección de Datos si considera que el tratamiento de sus datos personales no se ajusta a la normativa vigente.

8. Seguridad de los datos

El responsable del tratamiento adopta las medidas técnicas y organizativas necesarias para garantizar la seguridad de los datos personales y evitar su pérdida, alteración, tratamiento o acceso no autorizado.

9. Enlaces a sitios web de terceros

Este sitio web puede contener enlaces a páginas web de terceros. El responsable no se hace responsable de las políticas de privacidad ni de las prácticas de dichos sitios web.

10. Modificaciones de esta política

El responsable se reserva el derecho de modificar la presente política de privacidad para adaptarla a novedades legislativas o cambios en el funcionamiento del sitio web. Las modificaciones se publicarán en esta misma página.
